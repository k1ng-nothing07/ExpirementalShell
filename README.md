                #ExpirementalShell

    A small terminal shell written in full C.

    ## Requirements:

        MSYS2 (will be changed later on after fixing the bug.) 
        [only for windows.]
        gcc (this will be used to compile the src code (es.c).)
        [only for linux.]
    
    ## Commands:

     pwd
     clear
     exit
     help
    
            (help can list the commands.)

    ## to install it/run it on linux:
    gcc es.c -o es (if you have downloaded the src code.)
    ./es (runs it)

    ## to install it/run it on windows:
        open MSYS2
        ./es.exe
